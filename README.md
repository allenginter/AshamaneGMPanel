Ashamane GM Panel v0.2.0

Install
1. If you are a server GM, you had better already have this knowledge or your people are fucked from the "get-go"
2. In game, type /gmpanel or /agm.

Behavior
- The addon does NOT send commands automatically.
- Clicking an Option box [button] places the generated GM command into the chat-edit box.
- Review the command and press Enter to submit it.
- IF you have permissions elevated to allow the command, it will then execute the command.

Examples
- Select a player, then click Player > Kill selected target. It places .die in chat.
- Select a dead player, then click Player > Revive selected target. It places .revive in chat.
- Select a player, then Spells & Auras > Apply aura to selected target, enter 642. It places .aura 642 in chat.

Notes
- This first version is compact and uses ONLY native WoW UI APIs for a Legion-era addon (7.0.3-7.3.2)
- This DOES NOT grant GM status nor flag your account as such....It worrks with existing authority
